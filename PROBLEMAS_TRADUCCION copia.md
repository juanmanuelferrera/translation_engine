# Problemas Potenciales en la Traducción y Cómo Evitarlos

---

## 1. ARTÍCULOS ANTE TÉRMINOS SÁNSCRITOS

### Problema
El español requiere artículos (el/la/los/las) antes de sustantivos, pero los términos sánscritos no tienen género gramatical evidente.

### Solución — Asignar Géneros Consistentes

| Término | Género | Artículo | Justificación |
|---------|--------|----------|---------------|
| Kṛṣṇa | masculino | — (nombre propio) | Es una persona masculina |
| Bhagavān | masculino | el Bhagavān | "El Señor" |
| Brahman | neutro/masc | el Brahman | Concepto abstracto |
| Paramātmā | masculino | el Paramātmā | "La Superalma" pero forma masculina |
| guru | masculino | el guru | Persona, generalmente masculino |
| māyā | femenino | la māyā | "La ilusión" |
| karma | neutro/masc | el karma | Ya establecido en español |
| dharma | masculino | el dharma | Ya establecido en español |
| yoga | masculino | el yoga | Ya establecido en español |
| bhakti | masculino | el bhakti | Estándar en traducciones |
| śakti | femenino | la śakti | "La energía" |
| mantra | masculino | el mantra | Ya establecido en español |
| prasādam | masculino | el prasādam | "El alimento santificado" |
| saṅkīrtana | masculino | el saṅkīrtana | Derivado de kīrtana |
| līlā | masculino | el līlā | Estándar en traducciones |
| jīva | femenino | la jīva | Estándar en traducciones |
| gopī | femenino | la gopī | Pastorcilla de vacas |

### Casos Especiales
- **Títulos de obras**: Usar artículo masculino
  - "el *Bhagavad-gītā*" o "la *Gītā*" (ambos aceptables)
  - "el *Śrīmad-Bhāgavatam*" o "el *Bhāgavatam*"
  - "el *Caitanya-caritāmṛta*"

## 2. SUSTANTIVOS COMPUESTOS INGLESES

### Problema
El inglés crea compuestos fácilmente: "Kṛṣṇa consciousness", "self-realization". El español necesita preposiciones o reestructurar.

### Soluciones

| Inglés | Español | Estructura |
|--------|---------|------------|
| Kṛṣṇa consciousness | conciencia de Kṛṣṇa | N + de + N |
| God consciousness | conciencia de Dios | N + de + N |
| self-realization | autorrealización | Prefijo + N |
| sense gratification | complacencia de los sentidos | N + de + N |
| material nature | naturaleza material | N + Adj |
| spiritual master | maestro espiritual | N + Adj |
| devotional service | servicio devocional | N + Adj |
| disciplic succession | sucesión discipular | N + Adj |
| living entity | entidad viviente | N + Adj |
| fruitive activities | actividades fruitivas | N + Adj |
| transcendental loving service | servicio amoroso trascendental | N + Adj + Adj |

## 3. FALSOS AMIGOS

### Problema
Palabras que parecen similares pero significan otra cosa.

| Inglés | NO traducir como | Traducir como |
|--------|------------------|---------------|
| actually | actualmente | en realidad, de hecho |
| eventually | eventualmente | finalmente, con el tiempo |
| sensible | sensible | sensato, razonable |
| argument | argumento (solo parcial) | razonamiento, disputa |
| realize | realizar (solo parcial) | darse cuenta, comprender |
| pretend | pretender | fingir, aparentar |
| success | suceso | éxito |
| lecture | lectura | conferencia, clase |
| assist | asistir (solo parcial) | ayudar |
| introduce | introducir (solo parcial) | presentar |
| compromise | compromiso (solo parcial) | acuerdo, transigir |
| resume | resumir | reanudar |

## 4. TIEMPOS VERBALES

### Problema
El inglés tiene menos tiempos verbales que el español. El presente simple inglés puede requerir diferentes tiempos en español.

### Soluciones

| Contexto | Inglés | Español |
|----------|--------|---------|
| Verdad universal | "The Lord says..." | "El Señor dice..." (presente) |
| Cita de escritura | "It is stated..." | "Se afirma..." (presente) |
| Narrativa pasada | "Arjuna said..." | "Arjuna dijo..." (pretérito) |
| Condicional | "If one surrenders..." | "Si uno se rinde..." (presente) |
| Subjuntivo | "that he may attain..." | "para que pueda alcanzar..." (subjuntivo) |
| Imperativo suave | "One should understand..." | "Uno debe comprender..." (debe + infinitivo) |

### Subjuntivo — No Olvidar
El español requiere subjuntivo donde el inglés usa indicativo:

- "so that he can understand" → "para que pueda comprender"
- "in order that one may attain" → "a fin de que uno alcance"
- "whoever desires" → "quienquiera que desee"

| "nonsense" | absurdo | disparate, necedad |
| "so-called" | supuesto, falso | supuesto, llamado |
| "simply" (enfático) | simplemente, solo | simplemente |
| "very nicely" | muy bien | muy bien |
| "cent percent" | cien por cien | cien por cien |

| "on the bodily concept" | en el concepto corporal | en el concepto corporal |
| "fire in the belly" | hambre espiritual | fuego en el interior |

## 6. ORACIONES DEMASIADO LARGAS

### Problema
Algunas oraciones de Prabhupada exceden 100 palabras. En español pueden volverse confusas.

### Solución
- **NO fragmentar** en oraciones cortas (perdería el estilo)
- **SÍ usar puntuación clarificadora**: punto y coma, dos puntos, guiones
- **Verificar que el sujeto queda claro** a lo largo de la oración

### Ejemplo Problemático:
> "One who, understanding that his position is to serve, transfers himself to the service of the Lord, and thus becomes eligible for Vaikuṇṭhaloka, where there is no material misery, and where the living entity can live eternally, is considered the most intelligent."

### Solución:
> "Aquel que, comprendiendo que su posición es servir, se transfiere al servicio del Señor —y así se vuelve elegible para Vaikuṇṭhaloka, donde no hay miseria material y donde la entidad viviente puede vivir eternamente— es considerado el más inteligente."

(Uso de guiones largos para aclarar la subordinada extensa)

## 7. PLURAL GENÉRICO EN INGLÉS

### Problema
El inglés usa plural para generalizaciones: "devotees", "brāhmaṇas", "living entities".

### Solución
Mantener el plural, pero considerar:
- "devotees" → "los devotos" (con artículo definido para generalización)
- "a devotee" → "un devoto" (individuo genérico)
- "the devotee" → "el devoto" (arquetipo)

## 8. VOZ PASIVA INGLESA

### Problema
El inglés usa pasiva frecuentemente. El español suena forzado con pasiva perifrástica.

### Soluciones

| Inglés (pasiva) | Español ✗ | Español ✓ |
|-----------------|-----------|-----------|
| "is said" | "es dicho" | "se dice" |
| "is understood" | "es entendido" | "se entiende" |
| "is recommended" | "es recomendado" | "se recomienda" |
| "is accepted" | "es aceptado" | "se acepta" |
| "is performed" | "es realizado" | "se realiza" |
| "was given" | "fue dado" | "se dio" / "le fue dado" |

### Excepción — Mantener Pasiva Perifrástica
Cuando hay agente expreso:
> "The instruction was given by Kṛṣṇa" → "La instrucción fue dada por Kṛṣṇa"

## 9. REFERENCIAS CRUZADAS Y CITAS

### Problema
Las referencias a otras escrituras deben coincidir con traducciones existentes.

### Solución
Usar nomenclatura estándar:

| Abreviatura | Obra completa |
|-------------|---------------|
| Bg. | Bhagavad-gītā |
| SB | Śrīmad-Bhāgavatam |
| Cc. | Caitanya-caritāmṛta |
| NOD | El néctar de la devoción |
| NOI | El néctar de la instrucción |
| TLC | Las enseñanzas del Señor Caitanya |

## 10. MAYÚSCULAS

### Problema
El inglés capitaliza títulos y referencias a Dios de forma específica.

### Solución en Español

| Inglés | Español |
|--------|---------|
| the Lord | el Señor |
| the Supreme Lord | el Señor Supremo |
| He, Him, His (Dios) | Él, Le, Su (con mayúscula) |
| Personality of Godhead | Personalidad de Dios |
| the Absolute Truth | la Verdad Absoluta |
| Kṛṣṇa consciousness | conciencia de Kṛṣṇa |

### Importante
- **Mayúsculas en pronombres referidos a Dios**: "Él", "Su", "Le"
- **Minúsculas en pronombres referidos a otros**: "él", "su", "le"

## 11. NÚMEROS Y MEDIDAS

### Problema
Diferencias de formato entre inglés y español.

### Solución

| Inglés | Español |
|--------|---------|
| 5,000 years | 5.000 años (punto como separador de miles) |
| 3.14 | 3,14 (coma como separador decimal) |
| 10% | 10 % (espacio antes del símbolo) |

## 12. COMILLAS Y PUNTUACIÓN

### Problema
El inglés usa comillas dobles; el español de España prefiere comillas angulares.

### Solución

| Inglés | Español (España) |
|--------|------------------|
| "quoted text" | «texto citado» |
| 'nested quote' | "cita anidada" |

### Puntuación Final
- **Inglés**: El punto va dentro de las comillas
- **Español**: El punto va fuera si la cita no es oración completa

## 13. TRATAMIENTO DE "YOU"

### Problema
"You" inglés es ambiguo (tú/usted/vosotros/ustedes).

### Solución
- **Contexto didáctico general**: Usar "uno" o construcción impersonal
- **Diálogo directo (Kṛṣṇa a Arjuna)**: Usar "tú" (relación íntima)
- **Citas de escritura con "you"**: Evaluar contexto

## 15. PALABRAS POLISÉMICAS

### Problema
Algunas palabras inglesas tienen múltiples significados.

| Palabra | Significado 1 | Significado 2 |
|---------|---------------|---------------|
| service | servicio (devocional) | servicio (secular) |
| consciousness | conciencia (awareness) | consciencia (moral) |
| realization | realización (logro) | comprensión (understanding) |
| attachment | apego (espiritual) | adjunto (físico) |
| engagement | ocupación (actividad) | compromiso (promesa) |
| liberation | liberación (mokṣa) | liberación (física) |

### Solución
Elegir según contexto filosófico. En Prabhupada:
- "service" → casi siempre "servicio devocional" o "servicio"
- "consciousness" → "conciencia" (no "consciencia")
- "realization" → "comprensión" o "realización" según contexto
- "attachment" → "apego"
- "engagement" → "ocupación"
- "liberation" → "liberación"
